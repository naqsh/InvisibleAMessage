# Invisible Messages

A Windows desktop AI meeting assistant for authorized meeting audio, continuous transcription, question detection, and streaming suggested answers. See [Agent.md](Agent.md) for the project brief and recommended technology stack.

## Architecture

Audio capture → voice activity detection → streaming speech recognition → incremental question detection → streaming LLM inference → floating answer overlay.

## Getting started

The application has not yet been implemented. Setup and run instructions will be added as the project is built.

## Development

Prioritize the fastest useful and accurate answer. Measure end-to-end latency, evaluate provider costs and quality, and test supported capture and screen-sharing scenarios.
